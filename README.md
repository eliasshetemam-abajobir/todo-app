
# My To-Do List App

## About
This is my first JavaScript project. I built it to practice HTML, CSS, and JavaScript.

The app helps users organize their daily tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Add tasks by pressing Enter
- Count unfinished tasks
- Save tasks using localStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Add tasks and manage your to-do list.

## What I Learned
I practiced JavaScript functions, arrays, DOM manipulation, events, and saving data in localStorage.
